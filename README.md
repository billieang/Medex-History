# Medex History

## Features
- Import selectable-text PDF; review, edit, exclude, and confirm candidate results.
- Manual entry, historical charts, latest results, configurable reference ranges and high/low flags.
- Delete checkup records.
- Manual JSON backup and restore.
- PREVENT equation

## Important limitations
Scanned/image-only PDFs are unsupported. PDF.js loads from a CDN, so first-time PDF extraction needs internet; Browser data may be cleared; export backups regularly. Reference ranges are HATPEN thresholds.

## Install on Android
Open it in Chrome, then select **Install app** or **Add to Home screen**.
